# Soluciones Energéticas — Web corporativa

Sitio estático en **Astro** para [solucionesenergeticasreunidas.com](https://solucionesenergeticasreunidas.com).

## Desarrollo

```bash
npm install
npm run dev
```

## Formularios

1. Crea cuenta en [Web3Forms](https://web3forms.com) con destino `info@solucionesenergeticasreunidas.com`
2. Copia `.env.example` → `.env` y pega la Access Key
3. `npm run check:forms`

## Build

```bash
npm run build
npm run preview
```
